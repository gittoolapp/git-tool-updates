# Git Tool 0.3.6 Release Updates

## Key Highlights

* **Same-Tab Submodule Navigation:** Double-clicking an initialized submodule
  now opens it inside the current repository tab instead of spawning a new one.
  The tab label shows the `parent / submodule` context with a back affordance to
  the parent, and the submodule context menu still offers `Open in Current Tab`
  and `Open in New Tab`. The submodule context is preserved across tab switches,
  close/reopen, and restart.
* **Scrollable, Reorderable Repository Tabs:** Repository tabs no longer stop at
  15 or evict older worktrees. Every tab stays in one horizontally scrollable
  row, the active tab is revealed automatically, and tabs can be reordered by
  dragging or with move-left/right shortcuts. Order, titles, active tab, and
  per-repository terminal layouts persist across restart.
* **Undo Whole-File Discard And Delete:** Discarding tracked changes, deleting
  untracked files, discarding a selection or folder, and Discard All can now be
  undone. The success notification offers Undo for about eight seconds,
  restoring exact content and file modes. Recovery snapshots survive restart for
  up to seven days and don't appear in the commit graph.
* **Tree View For Changed Files:** A new toggle on the right panel switches every
  changed-file list — working tree, commit and stash details, and
  pull-request/compare files — between the flat path list and an IntelliJ-style
  folder tree. Folder rows can stage, unstage, or discard everything inside, and
  the chosen view mode persists across restarts.
* **Snapshot Selected Files Into A Stash:** Working-tree file context menus can
  now create a stash from the selected files without removing those changes from
  the working tree.
* **Faster, Warmer Diffs:** Opening a file right after launch is much faster, and
  background prefetching now warms more files in parallel so the file you click
  next is usually already loaded. Deleted lines in the inline diff also show
  syntax highlighting as soon as the diff opens instead of staying uncolored.
* **Smoother Loading Transitions:** Switching commits, files, history revisions,
  graph scopes, and pull-request/compare refs now keeps the prior content
  visible under a subtle progress veil until the new content is ready, avoiding
  blank intermediate frames. The veil only appears once a load takes longer than
  a brief moment, so near-instant swaps stay crisp.
* **No Empty Flash Returning To The Working Tree:** Switching from a commit or
  stash back to the working tree no longer flashes an empty "No changes" state
  or briefly shows files in the wrong section before the fresh scan settles.
* **Diff Follows Rapid File Clicks:** Clicking several working-tree files in quick
  succession no longer leaves the diff stuck on a previously selected file, and a
  failed diff load can be retried by clicking the same file again.
* **No Accidental Checkout From Rapid Graph Clicks:** Double-click checkout now
  only fires when both clicks land on the same row (or branch/tag badge), so
  rapidly clicking different commit rows simply selects each one.
* **Conflict Resolution Reliability:** Resolved conflict rows stay coherent
  through working-tree refreshes (no jumping sections, losing `Undo`, or
  reverting to phantom conflicts), undoing a resolution waits for Git to confirm
  before changing the row, and the ready-to-complete banner now uses the same
  checks as the completion action.
* **No More "Too Many Open Files" On Repo Switching:** Fixed a file-descriptor
  leak that could crash repository reads after switching between repositories.
  The change watcher is now bounded by a descriptor budget and the app raises its
  open-file limit at startup.
* **No More Idle Refresh Storm:** External tooling that touches file attributes
  without changing content (Gradle daemons, IDE/Spotlight indexers, file-sync
  agents) no longer triggers a continuous stream of full repository refreshes
  while the app sits idle. Real edits, commits, and ref updates are unaffected.
* **Skipped Setup No Longer Re-Opens Onboarding:** After skipping first-run
  setup, opening a repository no longer drops you back into the guided wizard,
  and the skip now persists across restarts. The between-repository screens share
  one consistent button language and a cleaner centered card.
* **Protobuf Syntax Highlighting:** `.proto` files now render with syntax
  highlighting instead of plaintext.
* **Visual And Theme Polish:** Conflict action colors are vivid again, the
  app-wide danger red is calmer, terminal tabs match the repository tab styling,
  toolbar icon buttons have a clearer resting surface, inactive tab labels are
  more readable, and disabled/muted states stay legible across dark and light
  themes. Inline blame also survives file switches, the terminal tab strip lays
  out more compactly, and the dev dashboard gains a Panel Resize performance card.
