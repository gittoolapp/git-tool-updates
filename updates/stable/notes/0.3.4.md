# Git Tool 0.3.4 Release Updates

A high-level, user-facing overview of the major features and improvements in this release.

## Key Highlights

* **Seamless GitLab & Bitbucket Logins:** Connecting your accounts is now much smoother and more secure. Both platforms support modern browser-based sign-in (OAuth) and improved token access for browsing repositories and opening pull/merge requests directly in the app.
* **Comprehensive App-Wide Vim Mode:** Vim navigation is deeply integrated across the interface. You can now use Vim shortcuts to navigate everywhere—jumping between sidebars and panels, scrolling through lists (commits, branches, files), triggering quick actions (like checking out branches or creating PRs), and editing directly within diff and conflict inspectors.
* **Context-Aware Command Search:** The command palette is significantly smarter. It ranks commands based on the specific panel or workspace you are currently using, and allows you to instantly search and jump straight to specific commits, branches, files, or terminal tabs.
* **Human-Readable, Actionable Errors:** Errors (especially for authentication or bad Git configs) are now consolidated, translated into plain English, and include direct action buttons to help you quickly resolve the issue without spamming you with raw backend code.
* **Smarter Conflict Resolution & Diffs:** Reviewing resolved conflicts is much clearer. Diffs accurately compare your resolution against the incoming changes rather than showing a blank slate. The app also remembers your place better when switching between resolved and open conflict files.
* **Frictionless Git Operations:** Routine actions like merges, rebases, reverts, and cherry-picks will no longer get stuck or blocked if you have unrelated "protected" files in your workspace.
