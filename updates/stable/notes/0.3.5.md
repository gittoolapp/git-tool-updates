# Git Tool 0.3.5 Release Updates

## Key Highlights

* **Persistent Repository Tabs:** Keep a rolling window of up to 15 worktrees open in an environment, switch between them from a flat, low-contrast tab strip that lives inline in the title bar, rename tabs, close one or many from the context menu, and restore the active tab after restart. Opening another repository once the strip is full no longer errors: the oldest non-active tab is closed automatically to make room, and it stays restorable with `Mod+Shift+T` (Reopen Closed Repository Tab) just like a manual close. Only the active repository keeps watchers and streams running, repository-scoped events cannot overwrite another tab, and each repository remembers its terminal-tab layout. Tab shortcuts now default to plain `Mod+T` (new), `Mod+W` (close), `Mod+Shift+T` (reopen the most recently closed tab), `Mod+[` / `Mod+]` (previous/next), and `Mod+1`…`Mod+9` (jump to the first nine tabs, browser-style), arbitrated by focus — they defer only to a surface that owns the chord (a focused terminal for shell keys, a focused Monaco editor for find and bracket indent) and otherwise work everywhere, including from text fields. Open a terminal with `Mod+`` ` (Toggle Terminal). Switching between open tabs is now atomic: the current repository stays on screen (dimmed, with a thin progress bar) until the next one is fully loaded, then swaps in one shot — no "Loading repository…" blank and no empty-graph flash.
* **Settings No Longer Lost On Restart:** Closed a data-loss path where a transient or failed config read on launch (most likely when the app process is restarted, e.g. during development hot-reloads or two overlapping instances) could leave the app holding an empty configuration that a later save then wrote over your real data — wiping accounts, recent repositories, and identity rules. Loading now tells a genuinely missing config (first run) apart from one that merely could not be read, recovers from the last-known-good backup when the main file is unreadable or has been emptied, and saving now refuses to overwrite a config that still holds real data with an empty one. Config writes also use a unique temporary file so two running copies cannot corrupt each other's save.
* **Sharper Diff And Stash Actions:** Stashes can now be multi-selected for apply, pop, or drop, stash-detail files can be multi-selected and applied without dropping the stash entry, and Monaco diffs expose hunk plus selected-line stage/unstage/discard/revert actions from the contextual `Space k` menu. Right-clicking inside selected diff lines keeps the selected-line action range. The diff viewer now owns copy through its own context menu: Monaco's duplicate "Copy changed/deleted lines" lightbulb is gone, and right-clicking a deleted block exposes **Copy deleted line(s)** that copies exactly the removed original text — so deleted lines are finally copyable, independent of added/context lines. Right-clicking a freshly opened diff that is scrolled down no longer jumps back to the top.
* **More Reliable Popups And Keyboard Focus:** Context menus now clamp to the visible viewport, reliably focus keyboard-opened menu items even after mouse clicks or menu item updates, restore focus after Escape, and Settings blocks background Vim shortcuts while you type. File History, the repository switcher, and the Vim command search also support normal-mode row navigation; Escape from search fields focuses the highlighted row before `j`/`k` motion, and `i` or `/` returns to search input.
* **Clearer Vim Follow-up Polish:** Commit/stash detail file-list `j`/`k` now no-op at the first/last row instead of re-opening the current file, and the leader hint panel names branch, remote, tag, stash, submodule, and inspector prefixes instead of showing generic "More Actions" labels.
* **Preview And Inspector Vim Polish:** Markdown Preview now supports Vim scrolling, half-page jumps, boundaries, select-all, and copy, while commit/stash detail file rows can bridge inspector view commands into the center inspector instead of silently no-oping. Commit-detail `Space i d` now keeps or opens Diff view rather than toggling the inspector closed, view-mode clicks refocus the live Monaco editor, and the Vim mode pill reflects app-owned visual selection in read-only inspectors. Read-only Monaco inspectors no longer preselect a stray character when visual selection starts, and `Ctrl+D`/`Ctrl+U` now move by visible half pages with hidden diff hunks and top/bottom boundaries handled cleanly.
* **Quieter Vim Position Indicators:** Vim window and sub-zone tracking now stays active for relative numbers and leader routing without drawing large accent borders around panels; row highlights, relative numbers, menus, and the mode pill carry the visible position. Opening a repository with Vim mode enabled now focuses the commit graph immediately, so `j`/`k` can move from the current branch/HEAD row without pressing leader first.
* **Local Repository Creation:** The repository picker can now initialize a selected local folder with `git init` and open it immediately, without creating any hosted/origin repository.
* **More Useful Remote Branch Recency:** The remote branch list now keeps a `Recent` group (remote branches whose tip was updated in the last hour) based on Git branch metadata, so the group survives reopening the app instead of depending on branches fetched in the current session.
* **Commit Hook PATH Fixes:** App-created commits still run normal Git hooks, and Git commands now append common developer toolchain paths so hooks can find dependencies such as `gofumpt` more reliably from the desktop app.
* **Reliable WSL Provider Sign-In:** GitHub and GitLab device-code sign-in now opens one Windows browser page from WSL, keeps polling tied to the exact code shown in Settings, remains active when a launcher error is reported, detects missing Linux Secret Service storage before authorization can stall, and explains when the default keyring must be created or unlocked.
