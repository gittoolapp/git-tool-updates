# Git Tool 0.3.8

A small preparation release. Nothing in the app itself changes — this update
exists to get the next one to you.

## What this is for

The next version is a substantial rebuild: Git Tool becomes a real desktop
application with its own window, dock icon, and native menus. That rebuild
changes the app's internals enough that it cannot be delivered as one of the
small incremental updates you have been getting until now — it has to arrive
as a complete download.

This release teaches Git Tool how to fetch that download. Once you have 0.3.8,
the next update will be offered to you automatically, in the usual way.

## What changes

- **Update delivery.** Git Tool now retrieves updates from an authenticated
  location rather than a public one.
- **A longer download window.** The previous two-minute limit was sized for a
  14MB update and would have failed partway through a much larger one on a
  slower connection.
- **A fallback route.** If the update service cannot be reached, Git Tool falls
  back to its previous source, so it can always be reached with a fix.

## Everything else

Unchanged. No features, no fixes, no interface differences. If you notice
anything at all different about this version, that is worth reporting as a bug.
